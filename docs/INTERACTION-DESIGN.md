## 一、13 条场景路径（S01–S13）

> 每条路径 = 患者触发 → 页面动作 → 产物 → 落页 → 红线。看板 13 枚 chip 与下表一一对应（`data-scene`）。

| # | 患者触发（设计假设语料） | 动作（原型中可点击） | 产物 | 落页 | 红线 |
| --- | --- | --- | --- | --- | --- |
| S01 | 「POLE/MMR/p53 是什么意思？我这项怎么没做？」 | 看板 → 看我的分型与分子 → 三态卡 → 分型/治疗对照 | 三态解释 + 指南原文摘录 + 问题清单候选 | 2·分子三态 → 2·分型与治疗对照 | K1：未检测≠阴性；无判定列 |
| S02 | 「医生说我 MMR 缺失，是不是 Lynch？女儿要不要查？」 | 看板 → Lynch 与家系 → 肿瘤/胚系分表 → 家系（第三方 private）→ 告知计划 | 检测链记录 + 家系代号表 + 问题清单 | 5·MMR 与胚系检测 → 5·家系记录 → 5·告知与监测 | K2：不劝检测；无姓名；consent=1 |
| S03 | 「我还想要孩子，能不能先不切子宫？」 | 看板 → 保育治疗 → 决策档案 → 孕激素与监测 → 妊娠尝试 | 知情记录 + 活检时间线 + 尝试日期 | 4·保育决策档案 → 4·孕激素与监测 → 4·妊娠尝试 | K3：零推荐 / 零概率数字；活产非唯一成功 |
| S04 | 「绝经后又出血了」 | 看板「记一次出血」→ 出血日志 → 新增一条（5 字段） | 独立轨道时间线（量/天数/诱因） | 2·出血日志 | K4：无病因/性质/严重度列 |
| S05 | 「我这个分型要不要化疗？」 | 看板 → 分型与治疗对照 → 治疗路径（折叠卡） | 四型 × 三列引用表 + 五块阶段细节 | 2·分型与治疗对照 → 3·治疗路径 | K5：只引用，无推荐等级 |
| S06 | 「放疗后又干又痛，是不是我矫情？」 | 看板条件卡 → 私密症状（默认 private）→ 扩张与保湿 → 沟通准备 | 私密时间线 + 想问的问题 | 6·私密症状 → 6·扩张与保湿 → 6·沟通 | K6：三出口过滤；不自行设频率 |
| S07 | 「复诊要带什么？」 | 看板 → 就诊准备 → 材料清单 + 疑问清单 → 导出预览 | 两区导出（事实 / 看法与担心） | 10·就诊准备与导出 | private 默认过滤；不含本机路径 |
| S08 | 「该多久查一次？」 | 看板 → 随访日历 → 已发生随访表 | 节点 = 起点 + k×间隔 | 7·随访日历 | 不生成「下次总复查」；不暗示少查 |
| S09 | 「这次 CT 和上次比呢？」 | 随访日历 → 影像与阴道细胞学 | 同模态并列表 + 有指征/常规标记 | 7·影像与阴道细胞学 | 不推荐无症状常规；也不写「无需检查」 |
| S10 | 「体重一直涨，吃什么好？」 | 看板 → 长期随访与健康 → 体重与营养 → 新增一条 | 进食/体重记录；体重进一图秀 | 7·体重与营养 | 不给食谱/热量处方；不做道德评判 |
| S11 | 「我很怕复发，也怕身体不再是自己的」 | 看板 → 情绪与亲密 → 当下感受（双人）→ 身体意象 | 患者/照护者并列自评 + private 记录 | 8·当下感受 → 8·身体意象 → 8·生育焦虑 | 双主体不平均；private；不承诺消除恐惧 |
| S12 | 「还有没有我能参加的研究？」 | 看板 → 资料与就诊 → 试验线索 | 2026 登记线索（含 NMPA 待核验） | 10·试验线索 | 线索不是推荐；不判入组资格 |
| S13 | 「这些报告能不能整理一下？」 | 看板 → 资料库与导入 → 整理草稿与核对 | 导入队列 + 候选逐项确认/拒收 | 10·资料库 → 10·候选核对 | 候选不是事实；失败不产候选 |

**闭环规则**：每条路径必须能「进入 → 操作 → 看到结果 → 回看板一步」。原型在所有二级页底部提供「下一页：…」链，并保留「← 回看板」；`check:hvt` X2 对两档案各走 13 条。

## 二、CRUD 矩阵（事实层 + 可见性）

> 通用原则：**没有物理删除事实**——更正 = 登记新版本；只有「本人私密记录」允许本地撤回/删除（无外发）。
> 可见性三态：`shared`（默认事实）/ `private`（默认不进一图秀/摘要/导出）/ `third_party_private`（家系，必须 `consent=1`）。

| 模块 | 事实对象 | C（新增） | R（读取/展示） | U（更正） | D（撤回） | 可见性与三出口 | 落页 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 出血 | `bleeding_rows` | ✅ 5 字段表单 | 时间线 + 一图秀「出血天数」 | 新版本 | 不删（事实） | shared；无病因列 | 2·出血日志 |
| 检查 | `exam_rows` | 导入/候选 | 表格 + 原文 | 新版本 | 不删 | shared | 2·检查与活检 |

**三出口收敛**：`privateFilter(p, outlet)` 一个函数，`outlet ∈ {chart, summary, export}`；一图秀页、看板摘要、导出预览各调用一次。家系行只有 `third_party=1 && consent=1 && visibility=private` 才进入过滤集合；**不存亲属姓名**。

## 三、编辑与表单预算

- **显式编辑入口 ≤1 / 页**：只出现在页头（`button.primary` / `*-add`）。AI 协助是软按钮，不计入编辑。
- **表单 ≤6 字段**：原型 10 个表单，最大 5 字段（`bleed-add`）。

| 表单 | 字段数 | 落页 | 说明 |
| --- | --- | --- | --- |
| 记一次出血 | 5 | 2·出血日志 | 日期/模式/量/天数/诱因；不判病因 |
| 私密症状 | 4 | 6·私密症状 | 默认 private；0–4 自评 |
| 感受 | 4 | 8·当下感受 | 本人/照护者分开存 |
| 身体感受 | 2 | 8·身体意象 | private |
| 体重/进食 | 3 | 7·体重与营养 | 体重进一图秀 |
| 治疗登记 | 3 | 3·系统与内分泌 | 只记录 |
| 活检结果 | 2 | 4·孕激素与监测 | 病理原文 |
| 尝试/随访 | 2 | 4·妊娠尝试 | 只记时间线 |
| 导入资料 | 3 | 10·资料库 | 演示不读真实文件 |
| 添加疑问 | 1 | 10·就诊准备 | 只整理不回答 |

## 五、待 G1/G3 确认（不沉默）

1. 「出血日志」保持二级（本版）；若升为一级，需把一图秀降为看板二级（§6.9 张力 2）。
2. 分子「两层三态」（检查层面 5 值 + 标记层面 3 值）在 G3 冻结时定稿。
3. 家系与放疗后私密的 `visibility` 默认 `private` 是家族通用默认（shared）的例外，需写入 freeze-contract。
4. 试验线索的 NMPA 状态逐药「待核验」，未取到官方原文前不写「已获批」。
5. 私密记录「本人删除」与家族「删除不存在」的关系：仅私密行允许本地撤回，事实层仍只增不改。
