# 患者流程（PATIENT-FLOW）· 三流骨架（M1 填实）

流一：异常出血（自查前形态）——绝经后出血/月经改变 → 出血日志（时间线）+ 就医准备｜不做：不判病因。
流二：确诊与分子分型——病理 + MMR/p53/POLE；"我的分型是什么意思、要不要化疗" → 分子档案三态 + 分型/治疗对照（引用）｜不做：不判分型。
流三：保育或术后长期随访——年轻未育者保育治疗与活检节奏；放疗后私密健康；Lynch 家系沟通 → 保育路径档案 + 私密记录（三出口过滤）+ 家系记录（第三方 private）+ 复诊摘要。
反推原则同家族；与 cervical 重名率 ≤70% 实测（同妇科区域，重点验证刻意不同）。
